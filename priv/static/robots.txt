# Lumen Viae
#
# Search engines are welcome on the content pages: the mystery listings and
# the Scripture page are what anyone looking for a Rosary should be able to
# find. What is closed off below is the prayer flow itself, the console, and
# the API.
#
# Note that this file is a request and not a fence. It is obeyed by the
# crawlers that behave, which is most of them and not all of them. The
# completion figures are protected in the application instead - see
# LumenViaeWeb.Plugs.GuardCompletions - because anything that decides to
# ignore this file will ignore it completely.

User-agent: *
Allow: /
Disallow: /admin
Disallow: /api/
# The prayer flow. A crawler walking it gains nothing a category page does
# not already give it, and used to walk far enough to trip the Complete
# button and leave a Rosary nobody prayed.
Disallow: /meditation-sets/
# Praying an order of prayer, a page a prayer: the order's own page and
# each prayer's page already carry every word.
Disallow: /prayers/orders/*/pray
# A day of the Consecration walked a step a page: the day's own page
# already carries every prayer's name and every reading's opening.
Disallow: /consecration/days/*?step=
# Hours of Prayer's dated pages. /hours is today's and is welcome; every
# other day, hour and month is assembled by the Divinum Officium engine on
# first asking, across six centuries of dates, and a crawler following the
# calendar's arrows would ask for all of them.
Disallow: /hours/
# The Daily Missal's dated pages. /missal is today's and the Order of Mass
# is one fixed page, both welcome; every other day and month is fetched
# from Missale Meum on first asking, across six centuries of dates, and a
# crawler following the day's arrows would ask for all of them.
Allow: /missal/order-of-mass
Disallow: /missal/
